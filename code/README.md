# Code

This folder contains the MATLAB and Python source code used to generate the synthetic power-domination dataset and reproduce the analyses reported in the study.

## Repository layout

The scripts expect the main dataset at `../data/pds_propagation_final_results.csv`. The GitHub-ready copies in this folder use paths derived from each script location, so the repository can be cloned and run without editing local absolute paths.

The MATLAB network-generation functions are in `functions/`.

Some analysis scripts generate intermediate CSV files and figures in the `code/` folder or in script-specific output subfolders.

The original local research files were not modified; these are repository-ready copies only.

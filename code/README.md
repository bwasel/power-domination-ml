# Code

This folder contains the MATLAB and Python source code used to generate the synthetic power-domination dataset and reproduce the analyses reported in the study.

## Repository layout

The scripts expect the main dataset at `../data/pds_propagation_final_results.csv`. The repository-ready copies in this folder use paths derived from each script location, allowing the repository to be cloned and run without editing local absolute paths.

The MATLAB network-generation and helper functions are located in `functions/`.

Some analysis scripts generate intermediate CSV files, figures, or script-specific output folders within the `code/` directory.

The original local research files were not modified; the files provided here are repository-ready copies prepared for reproducibility and public archiving.
